# Montaperti Shooter per Windows

[**SCARICA IL GIOCO COMPLETO PER WINDOWS**](https://github.com/rigorage/montaperti-shooter/releases/latest/download/Montaperti-Shooter-Windows-1.2.0.zip)

Nella pagina apri **Assets** e scarica lo ZIP che inizia con **Montaperti-Shooter-Windows**. Estrai tutta la cartella e apri **Montaperti Shooter.exe**. Puoi creare un collegamento sul Desktop.

Dopo questo primo download, il gioco controlla gli aggiornamenti a ogni avvio e chiede se vuoi scaricarli: **Aggiorna e gioca** oppure **Gioca senza aggiornare**. Non serve un account GitHub. Senza internet parte la versione già scaricata.

Questo repository contiene solo i pacchetti firmati e il processo che li pubblica.
I file Shooter-app.zip e update.json servono all'aggiornamento automatico: per il primo avvio scegli lo ZIP Windows completo.
